# Resources

Reusable resources such as themes, templates, configuration examples, small utilities and generic integrations. A reusable solution does not require a standalone product or repository: small tools and integrations belong here when their implementation is environment-independent, even when one Hypershell deployment originally motivated them. Deployment-specific hosts, secrets, Compose ownership and runtime configuration stay with the consuming infrastructure.

## Themes

| Resource | Description |
|---|---|
| [Hypershell Neon for Homepage](themes/gethomepage/hypershell-neon/) | A CSS-only dark neon-glass theme for [Homepage](https://gethomepage.dev/), with responsive tabs, animated sections, unified service and bookmark cards, improved keyboard focus and a floating refresh control. |
| [Hypershell Mermaid for Obsidian](themes/obsidian/hypershell-mermaid/) | Semantic Mermaid node colors and compact edge labels for Obsidian Markdown and Mermaid Canvas fullscreen, with a screenshot and installation guide. |
